# Multi Website Responsive Testing Project

## Overview
This project contains a manual QA responsive testing report covering multiple real-world websites across different screen sizes.

## Websites Tested
- Amazon
- Atelier
- Wikipedia
- Forkify
- Dinner Calculator

## Screen Sizes Tested
- Desktop: 1280px
- Tablet: 768px
- Mobile: 375px

## Deliverables
- PDF report with screenshots and observations
- Optional screenshot folder for reference

## Objective
To validate UI responsiveness and layout adaptability across different devices as part of manual QA testing practice.

## Status
All tested websites passed basic responsive layout checks without major UI breaking issues.
